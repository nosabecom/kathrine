# Kathrine

Personal media server, Expo Android/Android TV apps, and a browser library/player. Original video and audio stream directly to capable devices. The Expo clients use Material Design 3 through React Native Paper. TV shows appear as one series card, with seasons, ordered episodes, per-user continuation, and Start from beginning. Continue watching keeps individual episodes and films. Local NFO information, posters, season covers, episode thumbnails and backdrops are used automatically. Missing metadata/artwork is enriched and cached from TVmaze (shows) and Cinemeta (films); file details stay expandable.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Open http://localhost:5173. First run creates .data/bootstrap-code (private); use it on the setup screen to create your owner account. Add your existing movie/show folders in Settings, then scan. FFmpeg and FFprobe must be installed and on PATH. Node 22.16+ and pnpm 11.17.0 are required.

```sh
pnpm check
pnpm test
pnpm test:ewaste
pnpm build
pnpm start
pnpm android:build
```

Ewaste's connection address is **https://ewaste.tail3123d8.ts.net**. Connect Tailscale on the playback device, including when at home. Kathrine binds only to 127.0.0.1:8765; private Tailscale Serve terminates HTTPS and proxies to it. Direct LAN access and the old HTTP port 8765 address are disabled. Secure session cookies are enabled. No public Funnel or router port forwarding is configured for Kathrine.

For an existing app saved with the old LAN address, open Settings, sign out, and connect again using the HTTPS address above. Local sign-out still works when the previous server address is unreachable. Accounts, libraries, favorites and viewing history remain on the same server. The Hisense has been reconnected to this address and updated to 0.3.1; its physical verification is recorded in [Validation results](docs/validation.md).

Ewaste deployment: `pnpm deploy:ewaste`. It checks the private Serve route and enforces loopback binding plus HTTPS cookies on every deployment. Initial Serve provisioning is `sudo tailscale serve --bg --https=443 --set-path=/ http://127.0.0.1:8765`; preserve the existing /qb handler and do not use Serve reset or Funnel. Runtime code lives under ~/kathrine/current; data, environment settings, setup code, and APKs live under ~/kathrine-data. View logs with `systemctl --user status kathrine` and `journalctl --user -u kathrine`. Enable lingering for the user so it starts without an SSH session. Deployment keeps earlier releases and does not modify source media or retained legacy data.

Jellyfin and its Caddy proxy were removed at the user's request. qBittorrent remains available through the private /qb route. Media paths intentionally remain under /home/nosa/jellyfin/; do not rename or delete them because the Jellyfin application is gone. Kathrine uses the system /usr/bin/ffmpeg and /usr/bin/ffprobe independently of Jellyfin.

`pnpm test:ewaste` compiles and runs the integration suite on Ewaste using its deployed production dependencies and FFmpeg. Its generated media, accounts, and databases are isolated in temporary directories and removed after the test; the live library and accounts are not changed.

The native apps are generated by Expo prebuild. [Android builds and device checks](docs/android.md) · [Architecture, playback limits, and current scope](docs/architecture.md) · [Validation results](docs/validation.md)

4K/8K, HDR, and Atmos require a capable receiving device/output and enough network bandwidth. Original streaming avoids server transcoding; it does not remove those physical limits. Video conversion is off by default on Ewaste. Audio-only conversion preserves compressed video but loses object-audio metadata. Physical 8K/Atmos output must be verified on actual equipment.
