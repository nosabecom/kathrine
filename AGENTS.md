# Kathrine

Use pnpm 11.17.0 for dependency installation and all scripts. Android clients live in apps/mobile and use Expo, expo-video, React Native TV, and React Native Paper Material Design 3. Native projects are generated by Expo prebuild; edit app.config.ts or config plugins rather than generated Android files. Both Android builds are exposed through `pnpm android:build`.

Use Ewaste for server deployment and integration tests. Use Godseye for Android builds, emulators, and device control.

Keep completed implementation work in version control. Commit coherent changes and push them to the configured GitHub remote unless the user explicitly requests local-only work. Verify the remote commit before handing the work back; do not leave the implementation untracked or only on disk.

Never commit media, server databases, credentials, APK signing keys, local.properties, or deployment environment files. Jellyfin and Caddy were removed from Ewaste at the user's explicit request; do not reinstall or restore them unless requested. Preserve /home/nosa/jellyfin/movies, /home/nosa/jellyfin/tvshows, /home/nosa/jellyfin/downloads, their NFO/artwork sidecars, retained legacy configuration/cache, and Kathrine's data. Keep qBittorrent and its private Tailscale /qb route. Kathrine uses system /usr/bin/ffmpeg and /usr/bin/ffprobe, not the removed jellyfin-ffmpeg8 package. Runtime checks should expect Kathrine, Tailscale and qBittorrent, without requiring Jellyfin or Caddy.

Default playback must preserve the source video and audio. Conversion must be explicit and explain what quality or audio metadata will be lost.

Run `pnpm check`, `pnpm test`, and `pnpm build` for server or web changes. Run `pnpm android:build` for native client changes when an Android SDK is available. Report physical-device verification separately from emulator or build checks.
